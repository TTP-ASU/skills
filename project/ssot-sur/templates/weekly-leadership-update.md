# Leadership weekly project update

Use this structure when drafting the weekly project update email. Pull from PROJECT-CONTEXT, Brief, PRD, and (optionally) recent meeting notes. Keep each section brief; call out risks and propose solutions.

---

**Subject:** [Project name] – Weekly update [date]

- **Project / phase:** Name, current phase (e.g. Discover, Review, Handoff).
- **Last 7 days:** Key progress (Brief/PRD updates, decisions made, meetings that moved the needle). Be concise.
- **Next 7 days:** Planned focus (e.g. finalize PRD section X, stakeholder review).
- **Decisions needed / blockers:** Open questions or blockers that need leadership input.
- **Risks / dependencies:** Call out risks explicitly; propose solutions or options (e.g. "Risk: X. Propose: Y or Z.").
- **Links:** Brief and PRD (Notion links from PROJECT-CONTEXT).
