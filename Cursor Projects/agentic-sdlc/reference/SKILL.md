# Reference (templates & standards)

Use this skill when the user wants to **align with templates**, **standards**, or **reference docs** (e.g. Product Brief Template, PRD standards, org playbooks).

## When to use

- "Use our Product Brief Template", "follow the PRD template", "what's our standard for X?", "reference doc", "template".

## What to do

1. **Identify what’s needed:** Template (Brief, PRD, runbook), standard (definition of done, release criteria), or reference doc.
2. **Find the source:**  
   - **Notion:** Use Notion MCP to open the template or doc the user names (e.g. "Product Brief Template" in Favorites).  
   - **Workspace:** Check for files in the project (e.g. `docs/`, `templates/`, or project-specific paths).  
   - **User:** User shares link or pastes the template.
3. **Apply:** Use the structure and wording to shape the current deliverable; call out required sections or fields.
4. **Gaps:** If something is missing from the template or standard, say so and suggest an addition.

## Integration

- **discover-define** uses reference for Brief/PRD structure.  
- **review** uses reference to check compliance.  
- **operate** uses reference for runbook/ops templates.
